## 📌 Project Overview

This repository contains **three frontend projects** combined into a single, fully functional restaurant website. All projects are built using **pure HTML, CSS, and JavaScript** with no external libraries or frameworks.

---

## 🗂️ Projects Included

### ✅ Project 1: Static Webpage Design
**Goal:** Build a clean, semantic, and accessible static webpage.

**Requirements Met:**
- ✅ Semantic HTML (`<header>`, `<main>`, `<footer>`, `<section>`, `<article>`, `<nav>`)
- ✅ Only **one** `<h1>` on the page
- ✅ No inline styles — all CSS in external file
- ✅ No IDs used for styling — only BEM classes
- ✅ CSS **Grid** for page structure (cards, footer)
- ✅ CSS **Flexbox** for component alignment (navbar, card footer)
- ✅ All images have explicit `width` and `height` attributes
- ✅ BEM naming convention (`card__image`, `card--offer`, `navbar__link`)

---

### ✅ Project 2: Responsive Web Layout
**Goal:** Build a responsive webpage that adapts to all screen sizes.

**Requirements Met:**
- ✅ Viewport meta tag for mobile
- ✅ CSS **Media Queries** for responsive design
- ✅ **Hamburger menu** with Popover API for mobile navigation
- ✅ **Fluid Typography** using `clamp()` for responsive font sizes
- ✅ **Touch-friendly** targets (minimum 44px touch targets)
- ✅ CSS Grid + Flexbox harmony for responsive layouts

---

### ✅ Project 3: Interactive Web Elements
**Goal:** Add interactivity to the webpage using JavaScript.

**Interactive Features:**
| Feature | Description |
|---------|-------------|
| 🌙 **Dark Mode Toggle** | Click to switch theme, saves preference in `localStorage` |
| 🔢 **Order Counter** | `+` and `−` buttons to increase/decrease count |
| 🛒 **Add to Cart** | Click to add items, updates cart status and total |
| 📖 **View Details** | Expand/collapse additional dish information |
| 📱 **Mobile Navigation** | Responsive hamburger menu with smooth overlay |

**JavaScript Concepts Used:**
- ✅ DOM Manipulation (`classList.toggle()`, `textContent`, `style`)
- ✅ Event Listeners (`addEventListener`)
- ✅ State Management (`let` variables, `localStorage`)
- ✅ Functions (small, single-purpose)
- ✅ IPO Loop (Input → Process → Output)
